# Even or Odd checker

A python a program that determines whether a number is even or odd assuming that the user input is a whole number by checking whether or not dividing it by 2 results to a remainder of 0
### How to RUN
1. Open your GitHub and look for repositroy "PRACTICE-EXERCISE" and open it in COLAB
2. Run the program by clicking the play button
3. Enter a whole number, and the program will determine if its odd or even
